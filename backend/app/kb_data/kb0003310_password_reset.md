title: Self-service password reset
category: Access > Password
last_reviewed: 2026-05-02
---

Employees can reset their own directory password without opening a
ticket:

1. Go to the self-service portal at password.company.internal.
2. Enter your employee ID and verify via the registered MFA method.
3. Choose a new password meeting the complexity policy (12+ characters,
   mixed case, number, symbol).
4. Allow up to 5 minutes for the change to propagate to all systems.

If self-service reset fails twice in a row, the account may be locked --
this requires a manual reset via IT and should be logged as a ticket.
